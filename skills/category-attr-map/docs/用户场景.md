## 场景一 · 使用者的日常用法

- **角色**：使用者
- **触发时机**：需要「类目属性映射」这件事有结果的时候
- **他会说**：`用 category-attr-map 帮我类目映射`
- **需要准备**：商品资料；目标平台
- **拿到什么**：多平台类目属性映射表
- **容易踩的坑**：类目选错会直接影响流量与合规，宁可给备选也不要拍板错

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 category-attr-map 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品资料 | ✅ | 缺失会导致输出不可用 |
| 目标平台 | ✅ | 缺失会导致输出不可用 |
| 各平台类目表 | ⬜ | 有则更好 |
| 历史映射关系 | ⬜ | 有则更好 |
