| 层 | 内容 |
|---|---|
| 使用层 | 同时运营 2-4 个平台、SKU 20-500 的卖家；员工定位：多平台运营助理·小铺 ｜ 一人店的"轻量 ERP"，只做真正用的 20% 功能 |
| 触发层 | 关键词 / 显式点名「库存水位计算」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「订单数据」，先做完整性检查。 → **销量速率+在途**：按该定义执行，并把用到的输入项显式写进产出。 → **安全水位**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | 水位/补货建议 |
