# 使用示例

技能：**一份资料多平台 Listing**（`wf-ecom-ops-listing-gen`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/title_gen.py --topic '保温杯怎么选' --platform 抖音 --audience '通勤人群' --n 5
```

**真实输出**：

```console
平台：抖音（标题上限 20 字）
1. 保温杯怎么选值不值？   [极简钩子] 10字
2. 保温杯怎么选到底值不值？   [疑问钩子] 12字
3. 别再保温杯怎么选了，这才是正确姿势   [反差冲突] 17字
4. 保温杯怎么选亲测   [极简钩子] 8字
5. 为什么你的保温杯怎么选没人看？   [疑问钩子] 15字

以下公式因缺少真实事实被跳过（脚本不会自造数字）：
  - 数字清单：缺 n → --numbers（素材里真实存在的数量，如卖点条数）
  - 结果前置：缺 benefit → --benefits（有出处的效果，如「省下每天2小时」，禁止自造）
  - 时间限定：缺 days/minutes → --days（有出处的上手周期）；--minutes（有出处的学习时长）
```

> 同一选题换平台换标题风格，抖音与小红书的最优句式完全不同

> **注意**：跨平台复用同一标题会被判**搬运**，风格必须重写而非复制。

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/title_gen.py --topic '保温杯怎么选' --platform 抖音 --audience '通勤人群' --n 5
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/title_gen.py --topic '保温杯怎么选' --platform 抖音 --audience '通勤人群' --n 5 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
